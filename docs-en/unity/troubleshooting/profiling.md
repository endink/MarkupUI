# Profiling

In **Project Settings > Markup UI**, set **Telemetry**. By default, all signals are disabled. Select **Tracing** to collect performance traces in the editor. Metrics (**Metrics**) is a reserved option that currently does not provide metric collection.

Click **Apply** and save. This setting will take effect on Markup UI Runtime initialization next time. Set **Tracing Export Folder** to specify the tracing file directory.
